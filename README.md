# Second Brain

A polished, dependency-free web app for collecting dictated thoughts, deadlines, ideas, and reminders into a soft searchable second brain.

## Features

- Soft pink, neutral, mobile-friendly visual design
- Searchable card-style thoughts with timestamps
- Colored category tags and aesthetic tags/icons
- Collapsible folders for YouTube Ideas, School, Travel, Deadlines, and Random Thoughts
- Date grouping inside each folder
- Recently Captured timeline
- Resurface old ideas section
- Large thought box for typed or dictated notes
- Browser voice-to-text dictation with clear listening/stopped states
- Automatic category assignment and short generated titles

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
