# Second Brain

A soft, minimal web app for quickly capturing messy creative thoughts, travel ideas, school notes, deadlines, and random sparks.

## Run locally

```bash
npm start
```

Then open `http://localhost:5173`.

## Features

- Quick thought capture with automatic timestamps
- Browser voice-to-text dictation via the Web Speech API
- Automatic category suggestions
- Recently Captured dashboard
- Collapsible category folders grouped by date
- Search across notes, categories, dates, and tags
- Auto-generated titles for long thoughts
- Resurface Old Ideas section for forgotten notes
- Realistic sample notes so the app feels lived-in on first load
